Get Started
Want to learn how to use QuickeR?
Creating a QR
Steps to create your first QR code
1. Click on the '+' button. 2. Expand the 'Main content' section. 3. Select the QR code type you want to create. 4. Enter the required data.
Optional
- Change error correction level On the 'Customization' section: - Add a custom logo - Change the QR's colors
5. Click on 'Save' button.
Library
Filtering and order
Order: By default, QRs are ordered from newest to oldest. To toggle the order, click on the arrow button. Filter: To filter by the pinned state, select the corresponding option.
Viewing QRs, actions and details
To view a QR, its actions and its details, click on its row/entry. Actions: - Delete - Export - Share - Pin The info is in their respective sections.
Exporting
There are three options to export a QR: - Export to gallery - Export to folder - Export to 3D model (.stl) -> protruding or insetting The images are always exported in .png format. A filename is required.
External codes
Adding an external QR code
Steps: 1. Click on the image icon above the '+'. 2. Select an image from your device. Done! The QR code will be automatically added to the library.
Customizing
Cusmizations: - The app's theme mode -> Light/Dark/System (Default) - The app's theme color
Tools
Tools available: - Export library to zip - Import library from zip - Clear library
